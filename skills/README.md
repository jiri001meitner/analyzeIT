# AI Agent Skills

This directory contains specialized skills and automated guidelines for AI
agents operating within the `analyzeIT` repository.

## Skill Structure

Each skill resides in its own subdirectory containing a primary `SKILL.md`:

```text
skills/
└── skill-name/
    ├── SKILL.md
    └── scripts/
```

The `SKILL.md` file defines explicit procedures, prerequisites, and execution
steps (e.g., compiling Wasm modules, running ingestion benchmarks, validating
Parquet schemas).
